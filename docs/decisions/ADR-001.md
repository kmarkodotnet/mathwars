# ADR-001 — Unity 6.3 LTS (6000.3) verzióválasztás

Státusz: ELFOGADVA · Dátum: 2026-11-16 · Döntéshozó: felhasználó (architect dokumentálja)

## Kontextus

A `math-horde.md` 2. szakasza explicit előírja: „Engine: Unity 6.3 LTS, a 6000.3
verziócsalád kompatibilis javítókiadása”. A fejlesztői gépen jelenleg a 6000.0.77f1 és a
6000.1.14f1 van telepítve; a 6000.3 LTS telepítése Unity Hubból folyamatban. A projekt
Androidra (ARM64) készül, URP renderinggel, Input System-mel, portrait orientációban.

## Döntés

A Unity projekt a **6000.3 LTS** verziócsaláddal jön létre, és a
`ProjectSettings/ProjectVersion.txt` ezt rögzíti. A meglévő 6000.0 / 6000.1 telepítésekkel
a projekt **nem** nyitható meg (Unity felfelé migrálna, ami nem visszafordítható). A CI és
minden fejlesztő ugyanazt a patch-verziót használja.

**Rögzített patch-szint: `6000.3.28f1`** — ellenőrizve 2026-11-16-án a fejlesztői gépen:
`C:\Program Files\Unity\Hub\Editor\6000.3.28f1\Editor\Unity.exe`, a következő, az Android
ARM64 IL2CPP buildhez szükséges modulokkal: Android Build Support, OpenJDK 17.0.18+8,
NDK r27c, SDK build-tools 36.0.0, platform-tools 37.0.1, platforms 34–37.

A `tests/` tükör-solution ettől **független**: tiszta .NET 9 SDK-val fordul, nem igényel
Unity telepítést (ADR-003).

## Alternatívák

| Alternatíva | Elvetés oka |
|---|---|
| 6000.0 LTS (már telepítve) | ellentmond a spec 2. szakaszának; lemarad a 6.3 URP mobil-optimalizációiról és a gyorsabb Editor iterációról |
| 6000.1 (Tech Stream) | nem LTS, 2 évig nincs támogatás, instabilabb mobilon |
| Unity 2022.3 LTS | elavult, a spec kifejezetten kizárja |

## Következmények

- **Pozitív:** egységes, LTS-támogatott alap; a 6.3 Android build pipeline (AAB, Play Asset
  Delivery) és URP mobil-profil out-of-the-box használható.
- **Negatív / kockázat:** a build-ellenőrzés blokkolt, amíg a 6000.3 telepítése be nem
  fejeződik. Addig a Fázis 2 (MathEngine) a `tests/` solutionön keresztül Unity nélkül is
  haladhat — ez az egyik fő indoka a hibrid teszt-stacknek.
- Minden Unity-függő agent (gameplay-dev, ui-dev, mobile-build-engineer) csak a 6000.3
  telepítése után kezdhet Editor-verifikációt; addig kódot írhat, de nem állíthatja, hogy
  a build zöld (spec 20. szakasz záró bekezdése).
- A verzióemelés (pl. 6000.3.x → 6000.3.y patch) megengedett; minor/major emelés új ADR-t
  igényel.
